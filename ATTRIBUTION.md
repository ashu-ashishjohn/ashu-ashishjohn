# Sources and assets

Design reference: [Animated GitHub profile guide](https://github.com/Meghamittal0920/Meghamittal0920/blob/main/animated-github-profile-2page-guide.pdf). The original terminal section is retained in the repository; the visible profile now follows the midnight glass portfolio guide.

Technology icons: [Simple Icons](https://github.com/simple-icons/simple-icons), version 16.34.0, CC0. Brand marks identify technologies and do not imply affiliation. Microsoft SQL Server is named in text rather than given an unrelated database brand mark.

Fonts: Ubuntu (Ubuntu Font Licence) and Source Code Pro (SIL Open Font License). WOFF2 subsets use renamed internal families. Their license notices are reproduced in `FONT-LICENSES.txt`.

Photo: Ashish John's existing public GitHub avatar. Character illustrations: generated with the built-in image generation tool using that photo as the reference. Original PNG alpha is preserved. Images and fonts are embedded inside the SVGs so there are no external image dependencies.

Contribution city: [github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib), MIT license, v0.9.3 pinned to commit 7d95e7d4cdc028dd1e1cbd957d65f35efb12ae39. It runs with this repository's normal GitHub Actions token. No personal access token is required.

The dashboard reads unauthenticated public GitHub endpoints. Repository totals, stars and followers refresh daily. The city reflects actual GitHub activity. No private repository names are included. Angular and AI with .NET are labelled as beginner learning areas; animations are decorative, not proficiency scores.
